Les codes expirent vite

Les codes Aniimo tiennent rarement plus de quelques semaines, et certains sont désactivés dès qu'un quota d'utilisations est atteint — sans préavis. Cette liste a été vérifiée le 16 octobre 2026. Si un code ne passe plus, signalez-le sur le Discord Aniimo France : nous le déplaçons dans les expirés le jour même.

Comment utiliser un code cadeau

La procédure prend moins d'une minute, à l'identique sur PC, console et mobile :

  1. Lancez Aniimo et ouvrez le menu Paramètres.
  2. Rendez-vous dans l'onglet Compte.
  3. Cliquez sur Échange de code cadeau (Gift Code Redemption).
  4. Collez le code en respectant exactement les majuscules, puis validez.
  5. Ouvrez votre boîte de réception en jeu pour récupérer les récompenses.
Astuce

Copiez-collez systématiquement plutôt que de retaper : une majuscule mal placée suffit à faire échouer l'échange. Les boutons ci-dessus copient le code d'un clic.

Où trouver de nouveaux codes

Les codes sont distribués à des moments précis :

  • sur les réseaux sociaux officiels d'Aniimo ;
  • pendant les diffusions en direct et les présentations de mise à jour ;
  • lors des événements et des paliers communautaires ;
  • à chaque sortie de patch — voir nos patch notes en français.

Le plus simple reste de laisser la communauté faire le travail : sur le Discord Aniimo France, les nouveaux codes sont relayés et traduits dès leur publication.
