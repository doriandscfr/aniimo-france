Les codes ont une durée de vie courte

Les codes Aniimo expirent souvent en quelques jours ou quelques semaines, parfois sans préavis. Cette page est vérifiée régulièrement : si un code ne fonctionne plus, signalez-le sur le Discord Aniimo France et nous le déplacerons dans la liste des codes expirés.

Comment utiliser un code cadeau dans Aniimo

La procédure prend moins d'une minute et fonctionne à l'identique sur PC, console et mobile :

  1. Lancez Aniimo et ouvrez le menu Paramètres.
  2. Rendez-vous dans l'onglet Compte.
  3. Cliquez sur Échange de code cadeau (Gift Code Redemption).
  4. Saisissez ou collez le code en respectant exactement les majuscules, puis validez.
  5. Ouvrez votre boîte de réception en jeu pour récupérer les récompenses.
Astuce

Copiez-collez systématiquement les codes plutôt que de les retaper : une majuscule mal placée suffit à faire échouer l'échange.

Où trouver de nouveaux codes Aniimo ?

Les codes sont distribués par les équipes du jeu à des moments précis :

  • sur les réseaux sociaux officiels d'Aniimo ;
  • pendant les diffusions en direct et les présentations de mise à jour ;
  • lors des événements et des paliers communautaires ;
  • à l'occasion des sorties de patchs — voir nos patch notes en français.

Le plus simple reste de laisser la communauté faire le travail : sur le Discord Aniimo France, les nouveaux codes sont relayés et traduits dès leur publication.
